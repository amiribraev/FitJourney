# FitJourney Web

Next.js web app and backend API for FitJourney.

The mobile app now lives in a separate repository:

https://github.com/amiribraev/FitJourney-mobile

## Development

```bash
npm install
npm run dev
```

The local web/API server runs on:

```text
http://localhost:9002
```

## Environment

Keep Firebase admin credentials only in this web/backend project. Do not put private service account keys in the mobile repository.
